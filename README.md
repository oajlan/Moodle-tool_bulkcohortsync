# دليل أداة مزامنة الأفواج الدفع الدراسية بالمقررات بالجملة (Bulk Cohort Course Sync)
### أداة مخصصة لنظام Moodle LMS

---

## 📌 1. نبذة عن الأداة
أداة **Bulk Cohort Course Sync** هي إضافة رسمية مخصصة لنظام إدارة التعلم **Moodle** (من نوع `admin/tool`). تهدف الأداة إلى حل مشكلة الربط اليدوي المتكرر بين الزمر (الأفواج/Cohorts) والمقررات الدراسية (المواد/Courses).

تتيح هذه الأداة لمسؤولي الموقع (Admins) تحديد عدة زمر وعدة مقررات دراسية في وقت واحد، وربطهم بنقرة زر واحدة دون الحاجة للدخول لكل مقرر على حدة وإضافة طريقة التسجيل يدوياً.

---

## ✨ 2. المميزات الرئيسية

* ⚡ **المزامنة الجماعية (Bulk Sync):** ربط عشرات الأفواج بعشرات المقررات الدراسية دفعة واحدة.
* 🌳 **شجرة تصنيفات هرمية (Hierarchical Category Tree):** 
  - عرض المقررات مقسمة ومجمعة حسب الكليات والأقسام وتصنيفتها الفرعية بشكل متداخل.
  - التصنيفات مطوية افتراضياً لتوفير المساحة وسهولة التصفح.
* 🔍 **تصفية وبحث مباشر:** البحث الفوري في قائمة المقررات والزمر بالاسم أو الرمز.
* ☑️ **خيارات تحديد ذكية:**
  - تحديد كافة المقررات داخل تصنيف معين بنقرة واحدة (شاملة المقررات في التصنيفات الفرعية).
  - تحديد الكل أو إلغاء التحديد لكافة العناصر بنقرة واحدة.
* 📱 **تصميم متجاوب بالكامل (Responsive UI):** متوافق مع كافة الهواتف الذكية والأجهزة اللوحية والشاشات الكبيرة.
* 🌐 **دعم كامل لتعدد اللغات (Multi-language):** ترجمة كاملة باللغتين العربية والإنجليزية تتغير تلقائياً مع لغة الموقع.
* 💻 **واجهة سطر الأوامر (CLI Script):** دعم كامل للتشغيل عبر الكوماند لاين للسيرفرات أو الأتمتة المجدولة (Cron jobs).

---

## 🛠️ 3. طرق التثبيت

### الطريقة الأولى: التثبيت عبر ملف ZIP (من لوحة تحكم مودل)
1. قم بتحميل الملف المضغوط `tool_bulkcohortsync.zip`.
2. ادخل إلى موقع مودل بحساب المدير، ثم انتقل إلى:
   `إدارة الموقع (Site administration) > الإضافات (Plugins) > تثبيت الإضافات (Install plugins)`
3. قم باسقاط ملف الـ ZIP واضغط **تثبيت إضافة من ملف ZIP**.
4. اختر نوع الإضافة `Admin tool` (أداة الإدارة) واضغط متابعة لإكمال التثبيت.

### الطريقة الثانية: التثبيت اليدوي عبر السيرفر (cPanel / FTP)
1. فك ضغط الملف وانسخ مجلد `bulkcohortsync`.
2. ارفع المجلد داخل مسار الإضافات على السيرفر:
   `your-moodle-root/admin/tool/bulkcohortsync`
3. افتح صفحة **إدارة الموقع** في المتصفح وسيتم التثبيت تلقائياً.

---

## 📖 4. دليل الاستخدام عبر الواجهة الرسومية (GUI)

1. **الوصول إلى الأداة:**
   - بعد التسجيل كمدير، اذهب إلى:
     `إدارة الموقع (Site administration) > المقررات الدراسية (Courses) > مزامنة الأفواج بالمقررات بالجملة (Bulk Cohort Course Sync)`
   - أو عبر الرابط المباشر: `https://your-moodle-site.com/admin/tool/bulkcohortsync/index.php`

2. **تحديد المقررات (العمود الأيسر):**
   - اضغط على اسم الكلية/التصنيف لفتح المقررات التابعة لها.
   - استخدم مربع البحث لأعلى لتصفية المقررات بالاسم أو رمز المادة (Shortname).
   - اضغط "تحديد الكل" لتحديد كافة المقررات المطلوبة.

3. **تحديد الزمر / الأفواج (العمود الأيمن):**
   - ابحث عن اسم الزمرة أو رقم الدفعة (idnumber).
   - حدد الزمر المطلوب ربطها بالمقررات المختارة.

4. **تحديد الدور والتنفيذ:**
   - اختر الدور المُراد منحهم إياه داخل المقررات (الافتراضي: **طالب / Student**).
   - اضغط على زر **ربط الزمر بالمقررات المختارة (Sync Cohorts to Courses)**.

5. **متابعة التقرير:**
   - يظهر لك سجل التقرير الملون أعلى الصفحة بأهم النتائج:
     - 🟢 **[SUCCESS]:** تم ربط الزمرة بالمقرر بنجاح.
     - 🔵 **[INFO]:** الزمرة مرتبطة بالفعل بهذا المقرر مسبقاً (يمنع التكرار).
     - 🔴 **[ERROR]:** تعذر الربط أو وجود خطأ.

---

## 💻 5. دليل الاستخدام عبر سطر الأوامر (CLI)

يمكن لمسؤولي السيرفر تشغيل السكربت عن بعد عبر التيرمنال:

```bash
php admin/tool/bulkcohortsync/cli/sync.php --courses=CS_101,CS_102 --cohorts=32-27,32-28 --role=student
```

### خيارات الكوماند لاين:
* `--courses`: قائمة بأسماء اختصارات المواد (Shortnames) أو أرقام المعرفات (IDs) مفصولة بفواصل.
* `--cohorts`: قائمة برموز الأفواج (idnumbers) أو أسمائها أو المعرفات الرقمية مفصولة بفواصل.
* `--role`: رمز الدور المراد تعيينه (الافتراضي: `student`).
* `--help`: عرض تعليمات المساعدة وطريقة الاستخدام.
