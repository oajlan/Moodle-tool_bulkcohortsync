# Moodle-tool_bulkcohortsync
إضافة رسمية مخصصة لنظام إدارة التعلم Moodle (من نوع admin/tool). تهدف الأداة إلى حل مشكلة الربط اليدوي المتكرر بين الزمر (الأفواج/Cohorts) والمقررات الدراسية (المواد/Courses).  تتيح هذه الأداة لمسؤولي الموقع (Admins) تحديد عدة زمر وعدة مقررات دراسية في وقت واحد، وربطهم بنقرة زر واحدة دون الحاجة للدخول لكل مقرر على حدة وإضافة طريقة التسجيل يدوياً.
